# spedxploit

SpedXploit is a small archival x86 project for the 2015 Roblox client. The code is client-build specific and is not maintained for current Roblox, it was not made for live usage, just for the fun of it.
No injector or prebuilt DLL is included.

## disclaimer

This repository contains legacy client-side experimentation code preserved for archival and educational purposes.

It is not intended for cheating, bypassing protections, or violating any platform’s Terms of Service.

Use at your own risk. The authors do not endorse unauthorized use.

## reminder
You need to have Lua 5.1 folder installed on the C:\ or project directory. Compilation is pretty straightforward.

## note

This is old research/compability code, not a supported exploit release. This was made solely for educational purposes and fun. Enjoy.
